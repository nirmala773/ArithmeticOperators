# 🧮 Arithmetic Operators in Python

A simple Python project demonstrating the implementation of basic arithmetic operations using functions. This project is designed for beginners to understand how functions work and how user input is handled in Python.


## 📌 Overview

This program performs fundamental arithmetic operations:

* Addition
* Subtraction
* Multiplication
* Division

It takes input from the user and displays the results for each operation.


## 🛠️ Tech Stack

* Python 3


## 📂 Project Structure

```
ArithmeticOperators/
│── fun_add.py
│── README.md
```

## 🚀 How to Run

1. Clone the repository:

```
git clone https://github.com/nirmala773/ArithmeticOperators.git
```

2. Navigate to the project directory:

```
cd ArithmeticOperators
```

3. Run the Python file:

```
python fun_add.py
```


## 💻 Usage

* Enter the first number when prompted
* Enter the second number
* The program will output:

  * Sum of the numbers
  * Difference of the numbers
  * Product of the numbers
  * Division result


## 🧠 Concepts Used

* Python Functions
* User Input (`input()`)
* Type Casting (`int()`)
* Basic Arithmetic Operations
